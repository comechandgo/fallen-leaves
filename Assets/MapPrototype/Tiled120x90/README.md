# 120×90 Tiled 地图包

这是《秋风落叶》五分钟版本的一次性开放大地图源文件。交付内容只包含地图、地图模板、地图预览和地图说明。

## 当前地图规则

- 地图固定为120×90格，每格32px，对应游戏内1m。
- 地图从开局完整开放，不使用区域解锁或空气墙。
- 不设置叶子生成区。叶子和杂物由游戏逻辑在全图可行走区域随机散落。
- 随机点需要避开河流、湖泊、障碍物，并保留默认1m安全距离。
- 河流与湖泊都是清理判定水域；叶子或杂物进入有效水面后可计为已清理。

## 文件

- `FallenLeaves.tiled-project`：Tiled项目和地图对象类型定义。
- `map_120x90_v1.tmj`：唯一权威地图源文件。
- `templates/`：河流、湖泊、障碍、装饰和点位模板。
- `preview/`：SVG和PNG地图预览。
- `docs/操作指南.md`：编辑、随机散落和交付流程。
- `docs/TILED_MAP_SCHEMA.md`：供程序或AI读取的字段规范。

## 最短使用流程

1. 安装Tiled 1.12.x。
2. 打开`FallenLeaves.tiled-project`。
3. 打开并编辑`map_120x90_v1.tmj`。
4. 保存后，将整个`Tiled120x90`文件夹交给程序或AI。

`.tmj`是地图的唯一数据源。PNG只用于查看，不参与数据读取。
