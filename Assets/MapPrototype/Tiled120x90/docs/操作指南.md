# 120×90地图操作指南

## 1. 安装并打开

下载安装Tiled Map Editor：

https://www.mapeditor.org/

建议使用1.12.x。依次打开：

```text
FallenLeaves.tiled-project
map_120x90_v1.tmj
```

先打开项目文件，可以加载河流、湖泊、障碍物等自定义类型和字段。

## 2. 地图基准

| 项目 | 数值 |
|---|---:|
| 地图格数 | 120×90 |
| 单格像素 | 32×32px |
| 游戏单位 | 1格=1m |
| 游戏边界 | x=-60～60，y=-45～45 |
| 开放方式 | 开局完整开放 |

地图中的A/B/C/D只是空间风格和导航标记，不会阻止玩家移动。

## 3. 图层

### `10_Regions`

策划区域范围，只描述空间职责：

- A：初始河岸与教学。
- B：开阔移动区。
- C：高密度林地导航区。
- D：古树地标与湖泊区。

区域不负责叶子或杂物生成。

### `20_River`

主河流折线。选中`MainRiver`后可移动控制点，并用`widthM`修改宽度。

河流具有以下清理判定字段：

```text
isCleanupTarget = true
acceptsLeaves = true
acceptsDebris = true
collectorMarginM = 1
```

### `25_Lakes`

湖泊对象图层。当前地图包含一个位于东南湿地区的`SouthWetlandLake`。

湖泊可使用椭圆或多边形表示。与河流相同，湖泊可以同时接收叶子和杂物并触发清理判定。

增加湖泊时，将`templates/Lake.tj`拖入本图层，再调整宽、高和位置。

### `40_Obstacles`

放置会阻挡移动或随机散落的树木、石头。`prefabKey`记录对应的游戏资源名。

### `50_Decorations`

放置芦苇和装饰树木。装饰默认不参与散落点排除，除非程序另有设置。

### `60_Landmarks`

放置古树等远距离视觉引导物。

### `70_GameplayPoints`

保存精确点位。目前包括`CameraStart`和预留的`WindStart`。

### `90_Notes`

策划说明文字，程序可以忽略。

## 4. 叶子和杂物随机散落

地图中没有叶子生成区图层。推荐程序按以下规则生成：

1. 在120×90地图边界内随机取点。
2. 如果点落入河流或湖泊，拒绝。
3. 如果点落入障碍物或距离障碍不足1m，拒绝。
4. 如果点距离地图边缘不足1m，拒绝。
5. 其余点作为叶子或杂物位置。
6. 重复直到达到当前游戏模式要求的数量。

顶层地图属性已经记录：

```text
scatterMode = RandomWalkableArea
scatterClearanceM = 1
scatterAvoidWater = true
scatterAvoidObstacles = true
```

具体叶子数、杂物数和类型比例由游戏模式负责，不写入地图。

## 5. 水域清理判定

河流和湖泊使用同一套结果：

```text
物体进入有效水面
→ 检查该水域是否接受该物体类型
→ 将物体标记为已清理
→ 增加对应资源或进度
→ 从场上移除物体
```

`collectorMarginM`表示判定边界向水域内部收缩的距离，避免物体只碰到岸边就被清除。

## 6. 使用对象模板

`templates/`中提供：

- `RiverPath.tj`
- `Lake.tj`
- `Obstacle.tj`
- `Decoration.tj`
- `GameplayPoint.tj`

模板可以从Tiled项目视图直接拖入对应图层。保留模板引用时，应把`templates`目录一起交给程序或AI。

## 7. 交给程序或AI

至少交付：

```text
FallenLeaves.tiled-project
map_120x90_v1.tmj
templates/
docs/TILED_MAP_SCHEMA.md
```

同时说明：

```text
以map_120x90_v1.tmj为唯一地图数据源；
保持120×90格、32px=1m；
不添加叶子生成区；
叶子和杂物在可行走区域全图随机散落；
20_River与25_Lakes都属于清理判定水域；
不得重命名标准图层。
```

## 8. 保存与检查

保存地图后检查：

1. 地图仍为120×90。
2. `20_River`至少有一条折线。
3. `25_Lakes`中的湖泊没有超出地图。
4. 没有`LeafSpawnArea`对象或生成区图层。
5. 对象ID不重复，`nextobjectid`大于最大对象ID。
6. 所有`prefabKey`仍指向存在的资源名。
